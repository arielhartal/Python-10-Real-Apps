# Python 10 Real Apps Collection

This repository contains a collection of 10 real-world Python applications demonstrating various technologies and frameworks.

## Projects Overview

### 1. **English Thesaurus App** (`English_Thesaurus/`)
- Dictionary and thesaurus application
- JSON data handling

### 2. **Feel-Good App** (`Feel-Good/`)
- Kivy-based mobile application
- User interface with hover effects
- User authentication system

### 3. **Face Detection** (`FaceDetection/`)
- OpenCV-based face detection
- Image processing and computer vision
- Real-time capture functionality

### 4. **Web Scraping App** (`webscrapping/`)
- Data extraction from websites
- CSV output generation
- Jupyter notebook analysis

### 5. **Finance/Stock Analysis** (`finance/`)
- Stock market data analysis
- Financial visualization

### 6. **Geocoder App** (`app10_geocoder/`)
- Location-based services
- CSV data processing
- Web interface

### 7. **Database Applications** (`database_section/`, `d_tkinter_sqlite3/`)
- SQLite database integration
- GUI applications with Tkinter
- CRUD operations

### 8. **Data Visualization** (`Bokeh/`, `Pandas/`, `Numpy/`)
- Interactive charts and graphs
- Data analysis and manipulation
- Scientific computing

### 9. **Mapping Application** (`mapping/`)
- Geographic data visualization
- Interactive maps
- GeoJSON processing

### 10. **OpenCV Image Processing** (`openCv/`)
- Image manipulation and processing
- Computer vision algorithms

## Technologies Used

- **Python 3.x**
- **Tkinter** - GUI development
- **Kivy** - Mobile app development
- **OpenCV** - Computer vision
- **Pandas** - Data analysis
- **NumPy** - Scientific computing
- **Bokeh** - Interactive visualization
- **Flask** - Web framework
- **SQLite** - Database
- **Beautiful Soup** - Web scraping

## Setup and Installation

1. Clone this repository:
   ```bash
   git clone <repository-url>
   cd "Python 10 Real Apps"
   ```

2. Install required dependencies:
   ```bash
   pip install -r requirements.txt
   ```

3. Navigate to any project folder and run the main application file.

## Requirements

- Python 3.7+
- See individual project folders for specific requirements
